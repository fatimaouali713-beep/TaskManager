
# TaskManager

Application web de gestion des tâches développée avec React.

## Fonctionnalités

- Afficher le nom TaskManager.
- Ajouter une tâche.
- Afficher le titre et la description.
- Afficher le statut.
- Afficher la date limite.
- Utiliser les composants React.
- Utiliser les props et useState.

## Technologies

- React
- JavaScript
- CSS
- Git et GitHub

## Installation

npm install

## Démarrage

npm run dev
